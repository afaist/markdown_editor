# README - Markdown Editor (PyQt6)

## Описание

Markdown Editor - это полноценный редактор Markdown с предварительным просмотром и поддержкой LaTeX-формул. Приложение позволяет создавать, редактировать и экспортировать документы Markdown с возможностью мгновенного просмотра результата.

**Версия:** 1.0  
**Технологии:** Python 3.8+, PyQt6, QtWebEngine, KaTeX

## Особенности

- ✏️ **Редактирование Markdown** - удобный текстовый редактор на основе QTextEdit
- 👀 **Предпросмотр в реальном времени** - обновление предпросмотра автоматически при вводе
- 📐 **Поддержка LaTeX** - встроенные ($...$) и блочные ($$...$$) формулы через KaTeX
- 📤 **Экспорт** - сохранение в HTML и PDF форматы
- 🎨 **Темы оформления** - переключение между светлой, тёмной и контрастной темами (для редактора и предпросмотра)
- 💾 **Автосохранение** - автоматическое сохранение черновика каждые 3 секунды
- 🔍 **Поиск и замена** - быстрый поиск и замена текста
- 📊 **Счётчики** - отображение количества символов и слов
- 📁 **Множественные файлы** - создание, открытие, сохранение и экспорт файлов

## Установка

### Требования

- Python 3.8 или выше
- pip (менеджер пакетов Python)
- PyQt6 и QtWebEngine

### Шаги установки

1. **Склонируйте репозиторий** (или скачайте файлы):

```bash
git clone https://github.com/yourusername/markdown-editor.git
cd markdown-editor
```

1. **Создайте виртуальное окружение** (рекомендуется):

```bash
python3 -m venv venv
source venv/bin/activate  # Linux/macOS
# или
venv\Scripts\activate  # Windows
```

1. **Установите зависимости**:

```bash
pip install -r requirements.txt
```

1. **Запустите приложение**:

```bash
python main.py
```

## Использование

### Основные функции

#### Редактирование текста

- Введите текст в левой панели (Редактор Markdown)
- Используйте кнопки панели инструментов для форматирования
- Предпросмотр обновляется автоматически в правой панели

#### Форматирование

- **Заголовки**: Используйте `#` для заголовков разных уровней или кнопки "Заголовок 1/2"
- **Жирный текст**: `**текст**` или кнопка **Жирный**
- **Курсив**: `*текст*` или кнопка *Курсив*
- **Списки**: Используйте `-` для ненумерованных списков
- **Цитаты**: Используйте `>` для цитат
- **Код**: Используйте triple backticks для блоков кода
- **Ссылки**: Используйте кнопку "Ссылка"

#### LaTeX-формулы

- **Встроенные формулы**: $a^2 + b^2 = c^2$
- **Блочные формулы**: $$\int_0^1 x^2 dx$$

#### Темы

**Тема предпросмотра**: кнопка "Тема" или меню "Вид" → "Тема: ..."

- Светлая (по умолчанию)
- Тёмная
- Контрастная

**Тема редактора**: кнопка "Тема редактора" или меню "Вид" → "Тема редактора: ..."

- Светлая (по умолчанию)
- Тёмная
- Контрастная

#### Экспорт

- **Экспорт в HTML**: Файл → Экспорт в HTML или кнопка в панели инструментов
- **Экспорт в PDF**: Файл → Экспорт в PDF (работает с QtWebEngine)

### Горячие клавиши

| Клавиши | Действие |
| --------- | ---------- |
| `Ctrl + N` | Новый файл |
| `Ctrl + O` | Открыть файл |
| `Ctrl + S` | Сохранить |
| `Ctrl + F` | Найти и заменить |
| `Ctrl + Z` | Отменить |
| `Ctrl + Y` | Повторить |
| `Ctrl + Q` | Выход |

## Архитектура

### Модули

- `markdown_editor.py` - основной модуль приложения (класс `MarkdownEditorPyQt`)
- `main.py` - точка входа
- `test_markdown_editor.py` - тесты

### Компоненты

1. **Редактор** - QTextEdit для ввода Markdown
2. **Рендерер** - преобразование Markdown → HTML с поддержкой LaTeX через KaTeX
3. **Предпросмотр** - отображение HTML с помощью QWebEngineView
4. **Экспорт** - сохранение в различные форматы (HTML, PDF)
5. **Автосохранение** - таймер для автоматического сохранения черновика

### Структура проекта

```text
markdown-editor/
├── markdown_editor.py    # Основной код приложения
├── main.py               # Точка входа
├── test_markdown_editor.py  # Тесты
```

## Поддержка

### Известные ограничения

- Для экспорта в PDF требуется QtWebEngine (встроен в PyQt6)
- Локальные скрипты KaTeX должны быть загружены (файлы в папке `katex/`)

### Решение проблем

**Проблема**: Ошибка при экспорте в PDF  
**Решение**: Убедитесь, что установлены все зависимости `pip install PyQt6 PyQt6-WebEngine`

**Проблема**: LaTeX-формулы не отображаются  
**Решение**: Проверьте, что файлы KaTeX находятся в папке `katex/` (katex.min.css, katex.min.js, auto-render.min.js)

**Проблема**: Модуль PyQt6 не найден  
**Решение**: Установите зависимости `pip install PyQt6 PyQt6-WebEngine`
