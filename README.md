# Markdown Editor (PyQt6)

Простой и функциональный редактор Markdown с предпросмотром в реальном времени и поддержкой LaTeX-формул.

## 📋 Описание

Markdown Editor — это desktop-приложение для создания и редактирования документов в формате Markdown с мгновенным предпросмотром. Поддерживает встроенные и блочные LaTeX-формулы через библиотеку KaTeX, несколько тем оформления, экспорт в HTML и PDF.

**Версия:** 1.0  
**Технологии:** Python 3.8+, PyQt6, QtWebEngine, KaTeX, Python-Markdown

## ✨ Особенности

- ✏️ **Редактор Markdown** — удобный текстовый редактор на базе QTextEdit с поддержкой форматирования
- 👀 **Предпросмотр в реальном времени** — автоматическое обновление HTML-предпросмотра при вводе текста (с задержкой 300 мс)
- 📐 **LaTeX-формулы** — поддержка встроенных (`$...) и блочных (`$...$`) формул через KaTeX
- 📤 **Экспорт** — сохранение в HTML и PDF форматы
- 🎨 **Темы оформления** — три темы для предпросмотра и три темы для редактора (светлая, тёмная, контрастная)
- 💾 **Автосохранение** — автоматическое сохранение файла каждые 3 секунды после изменений
- 🔍 **Поиск и замена** — диалоговое окно для поиска и замены текста
- 📊 **Статистика** — счётчики символов и слов в строке состояния
- 📁 **Управление файлами** — создание, открытие, сохранение, сохранение как
- 📝 **Поддержка расширений Markdown** — fenced code blocks, syntax highlighting, таблицы, оглавление
- 💿 **Последняя сессия** — автоматическая загрузка последнего открытого файла при старте

## 🚀 Установка

### Требования

- Python 3.8 или выше
- pip (менеджер пакетов Python)
- Операционная система: Linux / macOS / Windows

### Шаги установки

1. **Клонируйте репозиторий** (или скачайте файлы):

```bash
git clone <url-репозитория>
cd markdown_editor
```

1. **Создайте виртуальное окружение** (рекомендуется):

```bash
python3 -m venv venv
source venv/bin/activate  # Linux/macOS
# или
venv\Scripts\activate     # Windows
```

1. **Установите зависимости**:

```bash
pip install -r requirements.txt
```

1. **Запустите приложение**:

```bash
python main.py
```

## 📖 Использование

### Основные функции

#### Редактирование текста

Введите текст в левой панели (**Редактор Markdown**). Предпросмотр в правой панели обновляется автоматически при изменении текста.

#### Панель инструментов

| Кнопка | Действие |
| -------- | ---------- |
| Заголовок 1 | Вставляет `#` (заголовок H1) |
| Заголовок 2 | Вставляет `##` (заголовок H2) |
| Жирный | Обернёт выделение в `**...**` |
| Курсив | Обернёт выделение в `*...*` |
| Список | Вставляет маркированный список |
| Цитата | Вставляет `>` (блок цитаты) |
| Код | Вставляет блок кода с тройными бэккиками |
| LaTeX inline | Вставляет одиночный ` для формул |
| LaTeX block | Вставляет `$` для блочных формул |
| Ссылка | Открывает диалог для вставки ссылки |
| Тема | Циклическое переключение темы предпросмотра |
| Тема редактора | Циклическое переключение темы редактора |
| Открыть | Открывает диалог выбора файла |
| Сохранить | Сохраняет текущий файл |
| Экспорт в PDF | Экспортирует документ в PDF |

#### Форматирование

```markdown
# Заголовок 1
## Заголовок 2
### Заголовок 3

**Жирный текст** и *курсив*.

- Элемент 1
- Элемент 2
- Элемент 3

> Цитата

[Ссылка](https://example.com)

| Колонка 1 | Колонка 2 |
|-----------|-----------|
| Ячейка 1  | Ячейка 2  |

#### LaTeX-формулы

- **Встроенные формулы**: `$a^2 + b^2 = c^2
- **Блочные формулы**:

$$\int_0^1 x^2 dx = \frac{1}{3}$$

```

`inline code`

```python
def hello():
    print("Hello, World!")
```

#### Темы оформления

**Тема предпросмотра** (правая панель):

- Светлая (по умолчанию)
- Тёмная
- Контрастная

**Тема редактора** (левая панель):

- Светлая (по умолчанию)
- Тёмная
- Контрастная

Переключение: кнопка на панели инструментов или меню **Вид → Тема**.

#### Экспорт

- **Экспорт в HTML**: меню **Файл → Экспорт в HTML**
- **Экспорт в PDF**: кнопка **Экспорт в PDF** на панели инструментов или меню **Файл → Экспорт в PDF**

## 🏗️ Архитектура

### Структура проекта

```text
markdown_editor/
├── main.py                    # Точка входа

├── conftest.py                # Настройка pytest (Qt headless)

├── get_katex.sh               # Скрипт для загрузки KaTeX
├── README.md                  # Этот файл
├── katex/                     # Библиотека KaTeX
│   ├── katex.min.css          # Стили KaTeX
│   ├── katex.min.js           # Ядро KaTeX
│   └── auto-render.min.js     # Авто-рендеринг формул
└── venv/                      # Виртуальное окружение
```

### Компоненты

1. **MarkdownEditorPyQt** — основной класс, наследник `QMainWindow`
2. **Редактор** — `QTextEdit` с подсветкой текущей темы
3. **Предпросмотр** — `QWebEngineView` для отображения HTML
4. **Рендерер** — `render_markdown()` конвертирует Markdown → HTML через библиотеку `markdown` с расширениями
5. **LaTeX-процессор** — `process_latex_before_markdown()` извлекает формулы, заменяет их плейсхолдерами, затем восстанавливает
6. **Экспорт** — `export_to_pdf()` использует `QWebEngineView.page().printToPdf()` для генерации PDF

### Используемые расширения Markdown

- `fenced_code` — блоки кода с тройными бэккиками
- `codehilite` — подсветка синтаксиса в блоках кода
- `tables` — Markdown-таблицы
- `toc` — автоматическое оглавление

## 🧪 Разработка

### Запуск тестов

```bash
# Через unittest
python test_markdown_editor.py

# Через pytest
python3 -m pytest test_markdown_editor.py -v

# Быстрый тестовый скрипт
python test_runner.py
```

> **Примечание:** Для тестирования используется `QT_QPA_PLATFORM=offscreen`, чтобы запускать Qt без графической оболочки.

### Настройка тестов

Конфигурация pytest находится в файле `conftest.py` — создаётся единый экземпляр `QApplication` для всех тестов.

## 🛠️ Решение проблем

| Проблема | Решение |
| ---------- | --------- |
| Модуль PyQt6 не найден | `pip install PyQt6 PyQt6-WebEngine` |
| LaTeX-формулы не отображаются | Проверьте наличие файлов в папке `katex/` (`katex.min.css`, `katex.min.js`, `auto-render.min.js`) |
| Ошибка при экспорте в PDF | Убедитесь, что `PyQt6-WebEngine` установлен |
| Предпросмотр не обновляется | Проверьте, что JavaScript KaTeX загружен корректно |

### Загрузка KaTeX

Если файлы KaTeX отсутствуют, запустите скрипт:

```bash
bash get_katex.sh
```
