# README - Markdown Editor

## Описание

Markdown Editor - это полноценный редактор Markdown с предварительным просмотром и поддержкой LaTeX-формул. Приложение позволяет создавать, редактировать и экспортировать документы Markdown с возможностью мгновенного просмотра результата.

## Особенности

- ✏️ **Редактирование Markdown** - удобный текстовый редактор с подсветкой синтаксиса
- 👀 **Предпросмотр в реальном времени** - обновление предпросмотра автоматически при вводе
- 📐 **Поддержка LaTeX** - встроенные ($...$) и блочные ($$...$$) формулы через MathJax
- 📤 **Экспорт** - сохранение в HTML и PDF форматы
- 🎨 **Темы оформления** - переключение между светлой и тёмной темами
- 💾 **Автосохранение** - автоматическое сохранение черновика каждые 3 секунды
- 🔍 **Поиск и замена** - быстрый поиск и замена текста
- 📊 **Счётчики** - отображение количества символов и слов

## Установка

### Требования

- Python 3.8 или выше
- pip (менеджер пакетов Python)

### Шаги установки

1. **Склонируйте репозиторий** (или скачайте файлы):

```bash
git clone https://github.com/yourusername/markdown-editor.git
cd markdown-editor
```

2. **Создайте виртуальное окружение** (рекомендуется):

```bash
python3 -m venv venv
source venv/bin/activate  # Linux/macOS
# или
venv\Scripts\activate  # Windows
```

3. **Установите зависимости**:

```bash
pip install -r requirements.txt
```

4. **Запустите приложение**:

```bash
python main.py
```

## Использование

### Основные функции

#### Редактирование текста

- Введите текст в левой панели (Редактор Markdown)
- Используйте кнопки панели инструментов для форматирования
- Предпросмотр обновляется автоматически в правой панели

#### Форматирование

- **Заголовки**: Используйте `#` для заголовков разных уровней
- **Жирный текст**: `**текст**` или кнопка **Жирный**
- **Курсив**: `*текст*` или кнопка *Курсив*
- **Списки**: Используйте `-` для ненумерованных списков
- **Цитаты**: Используйте `>` для цитат
- **Код**: Используйте triple backticks для блоков кода

#### LaTeX-формулы

- **Встроенные формулы**: `$a^2 + b^2 = c^2$`
- **Блочные формулы**: `$$\int_0^1 x^2 dx$$`

#### Экспорт

- **Экспорт в HTML**: Файл → Экспорт в HTML
- **Экспорт в PDF**: Файл → Экспорт в PDF (требуется weasyprint)

## Поддержка

### Известные ограничения

- Для экспорта в PDF требуется установка дополнительных системных зависимостей (weasyprint)
- Встроенные LaTeX-формулы требуют подключения к интернету для загрузки MathJax

### Решение проблем

**Проблема**: Ошибка при экспорте в PDF  
**Решение**: Убедитесь, что установлены все зависимости `pip install weasyprint`

**Проблема**: LaTeX-формулы не отображаются  
**Решение**: Проверьте подключение к интернету (MathJax загружается с CDN)
