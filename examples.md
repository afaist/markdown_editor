### Встроенные формулы

Формула Пифагора: $a^2 + b^2 = c^2$

Уравнение Эйнштейна: $E = mc^2$

Число Эйлера: $e^{i\pi} + 1 = 0$

Гауссов интеграл: $\int_{-\infty}^{\infty} e^{-x^2} dx = \sqrt{\pi}$

### Блочные формулы

**Квадратичная формула:**

$$x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$$

**Интеграл Римана:**

$$\int_a^b f(x) \, dx = F(b) - F(a)$$

**Ряд Тейлора:**

$$e^x = \sum_{n=0}^{\infty} \frac{x^n}{n!} = 1 + x + \frac{x^2}{2!} + \frac{x^3}{3!} + \cdots$$

**Формула Стокса:**

$$\oint_{\partial \Sigma} \mathbf{F} \cdot d\mathbf{r} = \iint_{\Sigma} (\nabla \times \mathbf{F}) \cdot d\mathbf{S}$$

**Матрица поворота:**

$$R(\theta) = \begin{pmatrix} \cos\theta & -\sin\theta \\ \sin\theta & \cos\theta \end{pmatrix}$$

**Определитель матрицы 2×2:**

$$\det\begin{pmatrix} a & b \\ c & d \end{pmatrix} = ad - bc$$

## Решение уравнения

## Введение

Рассмотрим квадратное уравнение вида:

$$ax^2 + bx + c = 0$$

где $a$ не равен $0$.

## Дискриминант

Дискриминант вычисляется по формуле:

$$D = b^2 - 4ac$$

В зависимости от значения $D$ имеем:

- Если $D > 0$, два различных корня
- Если $D = 0$, один корень (кратный)
- Если $D < 0$, действительных корней нет

## Корни уравнения

Корни находятся по формуле:

$$x_{1,2} = \frac{-b \pm \sqrt{D}}{2a}$$

### Пример

Для уравнения $2x^2 - 5x + 2 = 0$:

- $a = 2$, $b = -5$, $c = 2$
- $D = (-5)^2 - 4 \cdot 2 \cdot 2 = 25 - 16 = 9$
- $x_1 = \frac{5 + 3}{4} = 2$
- $x_2 = \frac{5 - 3}{4} = 0.5$

## Код решения на Python

```python
import math

def solve_quadratic(a, b, c):
    """Решает квадратное уравнение ax^2 + bx + c = 0."""
    D = b**2 - 4*a*c
    
    if D > 0:
        x1 = (-b + math.sqrt(D)) / (2*a)
        x2 = (-b - math.sqrt(D)) / (2*a)
        return x1, x2
    elif D == 0:
        x = -b / (2*a)
        return x
    else:
        return None  # Действительных корней нет

# Пример
roots = solve_quadratic(2, -5, 2)
print(f"Корни: {roots}")  # Корни: (2.0, 0.5)
```
